# JOHAP × SAI — Graduate Research / HCI / Learning Edition

Derived from the user's completed NYU IDM JOHAP × SAI final version. Same interactive site architecture, moving SAI circles/sliders, case-study chapters, and original media files. All 299 asset files and 20 video files are retained.

**This is a distinct website. Do NOT overwrite the NYU IDM portfolio repository.**

## Fit
- Cornell / Michigan: HCI, information, systems and UX iteration
- Vanderbilt / Georgetown / NYU Steinhardt / UPenn: learning systems, interaction, feedback and prototyping
- UCLA / Columbia / UChicago / NYU Psychology: cognitive processes, careful methods and actual lab RA roles

## Local use
Open `index.html` with all CSS, JS and `assets/` in the same directory. The site uses local video and image paths, and Google Fonts if online. Do not upload the ZIP file itself to GitHub; extract first. GitHub Pages needs `index.html` at the repo root.
